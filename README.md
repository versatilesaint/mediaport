# MediaPort

Live broadcast graphics for churches and organisations: 227 overlay templates for OBS, FreeShow and a Stage display, controlled from one page, online through Cloudflare or offline through a local Hub.

Live address (planned): https://mediaport.koladelawal.org

## What's here now

- `docs/MEDIAPORT-BUILD-BRIEF.md`: the build brief (revision 4). Read it before writing code, and build in the phase order in §13.
- `docs/design/mediaport-os.html`: a clickable, single-file prototype of the control shell ("MediaPort OS", §7.1). Open it in a browser. It includes 30 themes, resizable windows, organisation management and simulated outputs.

The application itself (`packages/`, `apps/`) is not built yet. Phase 0 starts it.
